# 多维数据探查分析工具

离线版多维数据探查分析工具，涵盖数据源接入、交互查询、聚合统计、图表看板、预警通知与数据导出，所有分析配置与结果持久化到浏览器本地存储。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `data-explore-studio:entries` 这一项，或调用 `resetModule(模块)`。

## 趋势预测训练执行

预测模型（`forecast`）只保存训练数据集和特征字段；训练执行产出的**预测模型结果**业务数据落在
`forecastrun` 模块，编排在 `frontend/src/api/forecast-training.ts`，纯计算在
`frontend/src/data/forecast-engine.ts`，历史订单特征在 `frontend/src/data/order-features.ts`。

- **训练执行**：趋势预测页「执行训练」读取历史订单特征和训练数据集，按预测步长训练并生成预测值，
  产出待生效结果；训练批次号内嵌模型编号与数据集版本（`BATCH-FORE-0003-DATA-0002-001`），同源可见。
- **阻断发布**：样本不足（有效样本 < 30 条或 < 2 倍步长）、历史窗不足（< 28 天）、特征缺失时，
  发布被阻断并保留上一份可用模型；本次产出带不足标记的草稿，样本依据与冲突判定
  （「保留旧模型」与「不足草稿」两种做法的比较）都留在结果上。
- **幂等与竞态**：同模型 + 同数据集版本的非终态结果原地更新，竞态重试只生成一份结果；
  中断或异常记为「已失败」并写明异常原因，可「重试训练」。
- **报告口径**：报告只读取「已生效」且批次同源的结果，不合格草稿不会被当成已生效模型；
  趋势预测页的「报告读取口径」面板可直接核对。
- **验收场景**：DATA-0003 只带来促销特征更新且历史窗不足（5 天），对 FORE-0003 执行训练会停止生效，
  报告继续读取上一份完整预测（FRUN-0001，基于 DATA-0002）。
- **导出**：结果清单导出与列表条目一致；每条结果还可单独下载预测文件（元信息 + 预测明细）。
